# Advent of Cyber 2022 — TryHackMe

Room: https://tryhackme.com/room/adventofcyber4

Advent of Cyber is a collection of daily security challenges. The tasks can cover different subjects, so I should treat each day as its own small investigation rather than assume one technique solves the whole event.

## How I work through each day

I read the objective and note what evidence or environment the task provides. Before running a command, I check which machine or file it is meant for. For a Linux task, basic inspection tools may help; for a web task, I may need to inspect requests; for a cryptography task, I need to identify the data format before decoding it.

I keep a note of the command or action, why I used it, and the result that supports the answer. That makes it easier to revisit a day later without copying an answer that may not match the current task.

## Answers and flags

I should record answers only after verifying them against the actual day. Any real flag included in a public write-up should be replaced with `flag{hidden}`, while keeping the explanation of how I found it. I should not include a flag section on a day that does not actually provide a flag.

## What I took from the event

The event is useful for sampling different security topics and building a habit of solving small problems methodically. The value is not just finishing the calendar; it is understanding why the solution works and which underlying skill the task is teaching.
