# Advent of Cyber 2023 — TryHackMe

Room: https://tryhackme.com/room/adventofcyber2023

Advent of Cyber 2023 is a daily challenge collection with tasks across several security areas. Since each day has its own objective, I should read the task carefully and avoid carrying assumptions from one day's challenge into another.

## A repeatable workflow

I begin by identifying the supplied target, file, or environment. Then I choose a tool that fits the task, run the minimum useful check, and inspect the result. If the task involves code, I read enough of it to understand the behaviour. If it involves a service, I confirm what is actually running before choosing a technique.

## Keep evidence with the answer

For each day, I should record the important step and explain why it reveals the answer. If a flag is required, the public version should use `flag{hidden}` instead of the real value. Days without flags should not have an invented flag section. This keeps the write-up accurate instead of turning it into a list of made-up completions.

## What I took from the event

The main benefit is practice across different topics and tools. A good note should let me understand the reasoning later, not merely repeat a command. I should add the exact daily answers only after checking the current task page and the output from my own session.
