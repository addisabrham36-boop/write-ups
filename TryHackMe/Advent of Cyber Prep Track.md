# Advent of Cyber Prep Track — TryHackMe

Room: https://tryhackme.com/room/adventofcyberprep

This prep track is meant to help me get ready for Advent of Cyber by practising the basics before the daily challenges. The safest way to work through it is to use the exact task text and verify each answer, because a small wording difference can change what a question is asking.

## My approach

For each task, I read the objective twice and identify whether it asks for a concept, a command, a value from the provided environment, or a flag. I use the tool or source appropriate to that task and keep the evidence that supports the answer.

For command-line tasks, I should understand the options rather than paste a command blindly. For a question about a specific file or service, I should inspect the actual supplied artefact instead of relying on an answer from a different walkthrough or an older version of the room.

## Notes and answers

I should only write down an answer after checking it against the live task. If the room includes a flag, I redact the value in the public write-up as `flag{hidden}` and explain the steps used to find it. If a task does not provide a flag, I do not add a flag section just to make the page look complete.

## What I took from this room

The prep track is a reminder to build good habits before a larger challenge begins: read carefully, use evidence, understand commands, and verify answers. Accuracy is more useful than finishing quickly with a page full of guesses.
