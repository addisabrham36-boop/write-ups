## 1. ASCII Fundamentals

ASCII (American Standard Code for Information Interchange) is a 7-bit character encoding system mapping integers `0` through `127` to specific characters, letters, punctuation marks, and hardware control signals.

Examples:
- The symbol `@` is represented in decimal as **`64`**.
- Decimal code **`35`** corresponds to the **`#`** symbol.
- Decimal code **`7`** represents the **`BEL`** (Bell) audible control character.

---

## 2. Unicode Standards

Because 7-bit and 8-bit ASCII cannot encode writing systems beyond basic Latin alphabets, **Unicode** was created. It provides unique code points across UTF-8, UTF-16, and UTF-32 to represent global languages, mathematical symbols, and modern emojis.
