# Defensive Security Intro — TryHackMe

Room: https://tryhackme.com/room/defensivesecurityintro

Defensive security is about protecting systems, detecting suspicious activity, and reducing the damage caused by attacks. Offensive testing helps find weaknesses, while defensive work tries to prevent attacks and notice when prevention fails.

## Main defensive areas

A Security Operations Center monitors alerts and investigates events. Digital forensics helps reconstruct what happened using system artefacts. Incident response focuses on containing an incident and restoring systems safely. Threat intelligence provides information about attacker techniques and indicators that may help defenders recognise activity.

Defenders also use tools such as endpoint detection, firewalls, SIEM platforms, and network monitoring. The tools produce data, but analysts still need to interpret that data and decide what action is justified.

## A simple investigation

When an alert appears, I should identify the affected system and time, review the underlying event, and search for related activity. I should not assume an alert proves a breach. If the evidence suggests a real incident, it needs to be escalated through the proper process.

## What I took from this room

Defensive security is a combination of monitoring, investigation, response, and prevention. The aim is not to collect the largest number of alerts; it is to detect meaningful activity and respond based on evidence.
