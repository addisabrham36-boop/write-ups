# LLM Security

{% embed url="https://tryhackme.com/room/llmsecurity" %}

A comprehensive exploration of Large Language Model (LLM) security threats spanning data-based attacks (membership inference), model inversion, context window manipulation, and supply chain package hallucination.

---

## 1. Data-Based & Model-Based Threats

- **Membership Inference:** An attacker analyzes prediction confidences to determine whether a specific private record was used in training (`MI_SAMPLE_ALPHA`).
- **Training Data Extraction:** Prompting the model into reproducing verbatim sensitive training data.
- **Model Inversion:** Reconstructing underlying feature vectors or private identifiers (e.g. recovering confidential employee ID `7814`).

---

## 2. System & User-Level Threats

- **Context Window:** The system component assembling system instructions, retrieved RAG data, and user input into a single sequence.
- **Memory / Context Poisoning:** Manipulating long-term agent memory or conversational history to force unauthorized execution. Completing the memory poisoning challenge returns:
  `THM{MEMORY_POISONED}`
- **Package Hallucination:** Attackers identify hallucinated package names generated by LLMs and publish malicious packages under those exact names to compromise developer environments (e.g. rogue package `robbco-llm-audit`).
